      how constraints read
      
        
        
        An entry is a node, then optionally a rule, then optionally an end date:
        
        
        allow = pal.spawn where species in SheepBall,Lamball and level <= 20 until 2026-12-31
        
        
          
          
        • where field op value, chained with and / or —
            and binds tighter, so a and b or c is (a and b) or c
          • 
          
        • Type ? in any box to reach a list the field does not offer by itself —
            ?items, ?pals, ?traits from the game, and
            ?groups, ?players, ?permissions from this
            config. Keep typing after the name to narrow it
          • 
          
        • operators: in (comma-separated list), =, !=,
            <, <=, >, >=
          • 
          
        • a field the call does not carry fails the rule — a grant narrowed to
            "only Lamball" must not widen when the species is simply left out; that is what
            an if cell means
          • 
          
        • calls aimed at a player also carry target (@me is the
            caller), target_group and target_weight — the target's
            highest-weight group and its weight; a self-call weighs −1, beneath every rank
          • 
          
        • group operations carry group_weight, so "may assign groups, but only
            below your own" is where group_weight < 12
          • 
          
        • until 2026-12-31 (or …T14:30) ends the entry — once the
            stamp passes it is simply gone

            Build on this server
            
    
            Events in, actions out, from any language. Every form on the Commands tab is
      exactly the call below — nothing here is privileged over what a token can do.
            
    
              
      
            1. Create an API token on the panel's admin page — read for feeds, read and write
        for bots that act — and send it as Authorization: Bearer palup_….
              2. 
      
            2. Follow events by cursor. New events arrive with a growing cursor; a smaller
        one means the server rebooted.

              curl -H "Authorization: Bearer $TOKEN" \
  "http://this-host:3000/api/bridge/events?since=0&type=player.join,player.chat"
              3. 
      
            3. Act through one verb.

              curl -H "Authorization: Bearer $TOKEN" -X POST http://this-host:3000/api/bridge/call \
  -H "content-type: application/json" \
  -d '{"type":"player.give_item","target":"<player id>","data":{"item":"PalSphere","count":5}}'
              4. 
    
            
    
            GET /api/bridge/schema lists every capability with its parameters
      and whether it is live on this build. Full contract:
      docs/bridge.md ·
      capability reference ·
      runnable examples.
            
  
            

  
            
    
            Events 
            
    
            Live stream for this server run, refreshed every two seconds while this tab is
      open. Click a type to narrow it. An action's result travels the same stream.

              Command reference
              
    
              Every capability is a chat command, gated by the node of the same name —
      !player.heal, or the short form when nothing else claims it. Parameters go by
      position or key=value; @me is the caller, @Name an online
      player. Mods add their own commands (!lb, …) — those declare a word, a help line
      and a node, and parse their own arguments.
